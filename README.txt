Python Flask + XAMPP/MySQL

1. เปิด XAMPP แล้ว Start Apache และ MySQL
2. เข้า phpMyAdmin แล้ว Import database.sql
3. เปิด Terminal ในโฟลเดอร์นี้
4. pip install -r requirements.txt
5. python app.py
6. เปิด http://127.0.0.1:5000

รูปสินค้า/หลักฐานเลือกจากไฟล์ในเครื่องโดยตรง ไม่ต้องใส่ URL
ไฟล์รูปจะเก็บใน static/uploads
